# ⚠️本レポジトリのコメント及び変数名はAIによるものです。コメントと実際の動作は異なる場合があります

以下は本リポジトリに含まれる主なスクリプトの概要です。

- **ai.py**: Streamlitを利用したWebベースのAIチャットインターフェース。ローカルLLM（LM Studio経由）と対話できます。
- **discord_yomiage.py**: Discordのボイスチャンネルで、テキストチャンネルのメッセージを読み上げるボットです。
- **LAL_chat.py**: Discord上で動作するAIチャットボット。LM Studioをバックエンドとして利用します。
- **yt-dl.py**: Flaskで構築されたYouTube動画ダウンロード用のシンプルなWebアプリケーションです。
- **mining.py**: 暗号通貨のマイニング機能を持つスクリプトです。
- **px-bw.py**: 画像処理に関連するスクリプトです。
- **play_mp4.py**: MP4動画を再生するためのスクリプトです。
- **mp3_ocr.py**: MP3ファイルの音声をテキストに変換するスクリプトです。
- **mp4.py**: MP4動画の操作に関連するスクリプトです。
- **invidious.py**: Invidious（YouTube代替フロントエンド）関連の機能を持つスクリプトです。
- **file-change.py**: ファイルの変更を監視し、特定の操作を実行するスクリプトです。
- **cuda_test.py**: NVIDIA CUDA技術を用いてGPU性能をテストするスクリプトです。
- **vc_av.py**: 話者ごとに音量を正規化しながらリアルタイムで音声を処理するスクリプトです。
